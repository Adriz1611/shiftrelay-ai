# Showcase copy

**Project name:** ShiftRelay AI

**One line:** Ask what broke. Verify what changed. Hand off what’s been done.

**Submission description:** ShiftRelay is a voice-first incident workspace for engineers taking over a failed deployment. Ask what changed and it fetches the last passing run, the exact Git diff, and the failed job’s log. Review the proposed response before ShiftRelay posts to GitHub and Discord. The next engineer can start a fresh voice session and hear what failed, what was done, and what still needs checking. Agora handles the live conversation, Murf Falcon generates the speech, and the workspace shows evidence and receipts throughout.

**60-second recording cut:** Open on the spoken question. Cut to the highlighted manifest diff and actual validator error. Show the approval and receipts. End on the fresh-session handover, with the three evidence sources visible. If showing recovery, keep the simulated label in frame.
